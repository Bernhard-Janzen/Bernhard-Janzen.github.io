# Bernhard Janzen – Business Solutions

Digitale Strom- & Gas-Seite von Bernhard Janzen.

## Veröffentlichung mit GitHub Pages

1. Repository auf GitHub hochladen.
2. Settings → Pages öffnen.
3. Unter "Build and deployment" bei Source "Deploy from a branch" auswählen.
4. Branch "main" und Ordner "/ (root)" auswählen.
5. Speichern.

Danach stellt GitHub Pages die Website über eine öffentliche HTTPS-Adresse bereit.
